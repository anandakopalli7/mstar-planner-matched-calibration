### `c1_analyse_v03`: what was fixed

| R17 item | Fix |
|---|---|
| **C2** (D16 Choice 25) | A missing comparator fails Form B or H3 (`met` needs `missing == []`). `decide` returns NO-GO and names every missing comparator and arm. RETUNED is required for H4. An arm missing in a log is an error. NaN rates are an error. |
| **M1** (Choice 26) | Holm runs over the fixed family S = {H2, H3, H4, H6b, H10}, with m = 5. A failed gate, a missing p-value or an absent route enters with p = 1. |
| **m6** | "Confirmed" needs Holm's rejection **and** the bound-based verdict. |
| **m3** | An empty V_t or V^J is `vacuous` (p = None), never p = 0. |
| **m5** | ValidJ requires the pooled joint population to be evaluable. |
| **m2** | A fold in which M*Jx's λ did not qualify fails H3. |
| **m9** | No B4 is a failed condition, not a crash. `c` is required under `--c1`. |
| **m10** | Wording is given per tracker. A non-evaluable pooled cell is named as such. |
| **M3** | The H6–H9 inputs are given as `{path, sha256}` and checked. H9 is wired in and required while secondary. Any absent H6–H9 input is a failed condition. Run records' `c1_plan_sha256` and `c1_folds_sha256` are checked. |
| **C1** | `--c1` takes the plan from the hash log. The config, the analysis code and the folds must be bound. Within fits are checked by provenance; transfer fits by their bound source. |
| **M2** | `--standin`, `--reproduce` and `--smoke` refuse confirmatory run records and non-nuScenes caches. |
