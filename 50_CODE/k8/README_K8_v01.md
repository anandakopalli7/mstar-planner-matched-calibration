# K8 code (v01, 1 Nov 2026): the closed-loop study redesigned from the literature

Implements `90_DECISIONS/D14_K8_DESIGN_v02.md` sections 2–5 (requirements A1–A10 and A13 of its section 3; A11–A12 are manuscript text). K8 supersedes K7. Nothing here is frozen; nothing is gated on nuScenes; **nothing has been run on a confirmatory scene** — every output under `70_TESTS/k8_scratch/` comes from the 10 development scenes.

The harness, described correctly (D14 v02 section 2): nuScenes log replay; the **recorded** CenterPoint → CANMOT (T1) / Poly-MOT (T3) output at score ≥ 0.4 is replayed from the logged ego — **no tracker runs in the loop**; agents are non-reactive. *Decision mode* is one decision per keyframe from the logged ego's state (leash = the log, sensor offset 0); it carries the paired comparisons at identical states. *Loop mode* is the closed-loop replay with non-reactive agents (nuPlan's CL-NR); estimates only.

## How to run

```
cd 50_CODE/k8
PY=../env/canmot310/Scripts/python.exe
$PY -B tests/make_k8_sim_v01.py && $PY -B tests/make_k8_run_v01.py          # regenerate (idempotent)
$PY -B tests/test_k8_v01.py ../../70_TESTS/k8_scratch/k8_tests_v01.json        # tests (about 15 min)
$PY -B tests/k8_dev_check_v01.py --out ../../70_TESTS/k8_scratch/k8_dev_check_v01.json \
     --runs ../../70_TESTS/k8_scratch/dev_v01 --csv-dir ../../70_TESTS/k8_scratch/dev_csv_v01 --workers 6 --boot 2000
```

Single steps: `k8_run_v01.py --caches <train> <val> --fits <k7_fits_<t>_v01.json> --tag <t>_<mode> --mode decide|loop --out <dir> --dev [--arms ...] [--scenes ...]` and `k8_analyse_v01.py --runs <dir> --tags t1 t3 --manifests <t1 train/val MANIFEST.json> --out <json> --csv-dir <dir> --allow-dev --boot 2000 [--items <t1.npz> <t3.npz>] [--fits <t1.json> <t3.json>] [--modes decide loop]`. Without `--allow-dev` the analysis requires `--prereg` and a K8 freeze record (`check_binding`, kept in K7's form for a future freeze); without `--dev` the runner requires `--prereg`. **Do not run either without `--dev` / `--allow-dev` until a K8 plan is frozen.**

## The development-scene selection (exact)

`k8_run_v01.py --dev` with both caches of a tracker (`30_DATA/k6/cache_v02_<t>_train`, `cache_v02_<t>_val`) keeps the scenes of `DEV_SCENES` present in the manifests and asserts that all 10 are there. `DEV_SCENES` is K6's / K7's tuple, unchanged: `scene-0061, scene-0103, scene-0553, scene-0655, scene-0757, scene-0796, scene-0916, scene-1077, scene-1094, scene-1100` (the nuScenes-mini scenes). This is exactly what `k7_dev_check_v01.py` does (it calls `k7_run_v01.py --dev` with the same caches). The analysis under `--allow-dev` sets `DEV_SCENES = ()` (so these scenes are the data), relaxes evaluability to ≥ 2 scenes from ≥ 1 log and allows a non-finite sup-t quantile (zero-SE cells only), as K7's development analysis did; the development check uses B = 2000 (K7's used 200). Every confirmatory analysis excludes these 10 scenes (`DEV_SCENES`); the item counts (`--items`) exclude them by scene name.

The fits used are the K7 fits (`60_RESULTS/k7_fits_v01/k7_fits_<t>_v01.json`, cross-fitted on the 5 K6 log folds, seed 20261101); the development scenes take the fit of their own fold, as in K7.

## What changed from K7, file by file

### `k8_sim_v01.py` (from `k7_sim_v01.py`; see the generator's replacement list)

- **Arms** (D14 A2, A3). `ARMS = ARMS_K7 + ALPHA_ARMS + DELTA_ARMS` (22 arms incl. LOG). `B0a<α>`, α ∈ {1/4, 1/3, 1/2, 1, 2, 3, 4, 5} (labels `B0a0.25 … B0a5`; `ALPHA_OF_ARM` holds the exact values): B0's covariance `S_h + σ_a² I` scaled by α, so the margin is `√α · z_0.95 · sd` — **the annotation term σ_a² = 0.10² is scaled with the covariance** (stated in `margins()`). `B0d<δ'>`, δ' ∈ {0.05, 0.02, 0.01, 0.005, 0.001}: B0's covariance unchanged, margin `z_{1−δ'} · sd` (`Z_OF_DELTA`, hard-coded normal quantiles checked against scipy by T7). `B0a1` and `B0d0.05` equal B0 (checked by T4). `FITFREE` lists the arms that take no fit dictionary.
- **`plan_positions_speeds`** returns the candidates' speeds beside the arc lengths (same integration); `plan_positions` wraps it.
- **`plan_step(..., vlead=None, cal=None)`**: `vlead(t)` is the logged ego's speed at the leash's time (decision mode: `sc.v_log`; loop: delayed by the entry shift). After the (unchanged) choice it adds, per decision: `v_now`, `v_chosen` (the chosen candidate's planned speed 0.5 s ahead, capped at the logged speed when the plan is leashed there, as the closed loop caps it), `v_log` (the logged ego's speed 0.5 s ahead), `ds_plan` (the leashed planned arc length over the first 0.5 s), `ds_log` (the logged ego's over the same 0.5 s), `min_gap` (the smallest pair gap of the chosen plan over the enforced (track, check time) pairs within 2 s; pair gap = max over the object's axes of the buffered separation, the quantity the planner relies on), `ttc` (min over the tracks with an enforced pair of gap_now / closing, closing = (gap_now − gap at 0.5 s under the plan) / 0.5 s, 20 s when not closing, 0 when already inside the buffer, clipped at 20 s), `n_enf_tracks`, and the relied-on pair counts `stats` (below). "Longitudinal gap" in D14 A5 is implemented as this pair gap along the relied-on separating axis; the per-axis object-frame gaps are what the planner enforces.
- **`_record(..., arm, sd, pcov, cal)`** fills the K7 counts dict exactly as before and, new, returns the per-decision counts of the **relied-on pairs** (relied-on axis separating, enforced, satisfied — the pairs behind the PD7 records) by near (pair gap ≤ 5 m) × in-path: records and exceedances over all steps and at step 0 only (`ST_FIELDS`, 4 × 4). When `cal` is given it accumulates the **calibration table** per key `(near·2 + inpath)·96 + L0(relied axis)`: `CAL_FIELDS` = records, exceedances of the standardised error along the relied-on axis at δ ∈ {0.1, 0.05, 0.01, 0.001}, NEES sum and count, NEES outside / above the 95 % χ²(2) interval, ellipse coverage at 50/90/95/99 %, Gaussian NLL sum, energy-score sum, margin sums along the object's long and lateral axes.
- **Covariance per arm** (`_arm_cov`, D14 A6): Z0 none; B0 `S_h + σ_a² I`; B0a<α> `α(S_h + σ_a² I)`; B0d<δ'> `S_h + σ_a² I` (B0's; only the quantile changes); B1 `k(group, range)(S_h + σ_a² I)`; B3, B4 `(c/z)²(S_h + σ_a² I)`; B6, M* `A(S_h + σ_a² I)A` with `A = (c_long/z) a_l a_lᵀ + (c_lat/z) a_t a_tᵀ` — the deployable recalibrated covariance of `m_lib_v04.deploy_covariance` with the pair's (L0, in-path) thresholds (a margin ≤ 1e-3 m is replaced by 1e-3, as `deploy_covariance` replaces a threshold ≤ 0); B9 `(r²/χ²_{2,0.95}) I`. Every margin arm except B9 and the δ' arms is read generically as `D S' D`, `D = diag(margin_a / (z·sd_a))`, in the object's axis frame. Consequences: the exceedance-curve point at δ = 0.05 equals the per-constraint exceedance V1 (relied axis) for every margin arm except B9 (whose Gaussian reading has a smaller 95 % half-width than r) and the δ' arms (whose curve is B0's).
- **Energy score**: `ES = mean_i‖X_i − e‖ − ½ mean_i‖X_i − X'_i‖` with `X = L Z`, `L` the Cholesky factor of the arm's covariance, from `ES_DRAWS = 200` fixed standard-normal draws for `Z` and `Z'` (seed 20261108), the same draws for every record. The closed form was not used (the first term has none in 2-D). Test T3 checks it against fresh draws.
- **`run_decisions`, `run_episode`** return the per-decision records under `out["decisions"]` and the calibration table under `out["cal"]`, plus episode summaries (`mean_chosen_speed`, `mean_logged_speed`, `progress_ratio`, `backoff_counts`, `min_gap_mean`, `ttc_mean`, `share_ttc_lt_2s`, `divergence_share`, `anees_relied`, `p_v_relied`, `mean_margin_relied`, `records_relied`). All K7 summary fields are unchanged, including the closed loop's `trace_sha256`.

### `k8_run_v01.py` (from `k7_run_v01.py`)

Runs `k8_sim_v01`; `fits if arm not in S.FITFREE else None`; pops `decisions` and `cal` from each episode and writes `decisions_<tag>.npz` (`episode, k, ob, infeasible, lam, v_now, v_chosen, v_log, ds_plan, ds_log, min_gap, ttc, n_enf_tracks, stats`) and `cal_<tag>.npz` (`episode, key, values, fields`); the run record carries `decisions_sha256`, `cal_sha256` and the number of decisions. `--dev` selection and the `--prereg` design lock are unchanged (messages name K8).

### `k8_analyse_v01.py` (from `k7_analyse_v02.py`)

- **N1 (R12b)**: in `hk1_rule`, PD's power-qualified family must not be flagged in its own sup-t (`a_ok = a_ok and not r["family_flagged"]`); only the count floor stays reported on PD. R12b n1: the docstring names the design it implements. The other R12b minor items (n2–n6) concern the freeze script, the plan text and D11 and do not apply to these files.
- **Every K6/K7 validity test unchanged in form**: all-evaluable one-sided sup-t at 0.95 per population, pointwise pooled cell, power rule (0.15 / 0.80 / ρ = 0.5 / 200 datasets / first 500 weights), F_MIN = 6 on PD7 and SD1_7, evaluable-cell rule, Bonferroni across the three populations; HK2 on SD1_7 at 1 − 0.05/2; HK3 in K6's form at 1 − 0.05/4 with the dominance form reported; seeds `[20261106, i, 0|1]` and `[20261107, i]` as K7. All of it is **reported**: `hypotheses` carries the note, and `k7_form_reported_only` says what K7's rule would have said.
- **Validity for every arm**: `hk1_rule` is evaluated on every arm's own tables (`validity_by_arm`; power seeds `[20261107, i, 100 + arm index] + [k]` for the comparators), so D14 section 6 form B can be reported.
- **A1**: `V2` (per population PD7, SD1_7, PD, NIP: scene-level rate of decisions with ≥ 1 exceedance among the decisions with ≥ 1 relied-on record, log-cluster bootstrap interval, decision-level rate) and the **one-step check** `V1_one_step` (K7's pooled cell restricted to step 0) and `V2_one_step` (step 0 only).
- **A2/A3**: `sweep` with the α curve, the δ' curve and the references B0, B4, M*. **Retuned nominal** = the *largest* δ' (least conservative) whose pooled PD7 scene-level exceedance is ≤ δ (D14 says "the smallest δ'", which is degenerate under monotonicity — every smaller δ' also qualifies; the least-inflated qualifying arm is the meaningful reading and it is stated in the JSON `sweep.reading`). `retuned_alpha` = the smallest α with the same property. Both are compared with M* on the paired endpoints (`retuned_nominal_vs_Mstar`).
- **A4**: `endpoints_by_arm`: infeasible rate (K7 code, unchanged), `progress_ratio` (per scene Σ ds_plan / Σ ds_log), `mean_chosen_speed`, `mean_logged_speed`, `backoff_distribution` (shares at λ = 1, 0.75, 0.5, 0.25, 0, emergency stop), `estop_share`, `mean_backoff_level` (stop counted as 0).
- **A5**: `min_gap_mean`, `min_gap_share_lt_1m`, `min_gap_p10_decisions`, `ttc_mean`, `ttc_share_lt_2s`, `ttc_p10_decisions`.
- **A6/A7**: `calibration[pop][arm]`: ANEES with its χ² interval `[χ²_{2n}(0.025), χ²_{2n}(0.975)]/n` and `anees_in_interval`, scene-level ANEES with interval, p_v (and below/above), ellipse coverage at 50/90/95/99 %, the per-axis exceedance curve, mean NLL, mean energy score, mean margins long/lat (sharpness). Per stratum: `k8_<tag>_decide_cal_cells.csv` (cell = group × axis × motion, every population and arm) and `k8_<tag>_decide_cal_l0_PD7.csv` (L0 × in-path, PD7).
- **A8**: `counts`: scenes, logs, decisions per arm, records per population per arm (with scenes and logs), per cell for M* (with the fallback share), the items (`--items`, ref_relied items = one per pair, per population and cell, development scenes excluded), the folds (`--fits`), the scope notes (transductive scope; CANMOT-SC val tuning; no tracker in the loop).
- **A9**: NIP in every table (cells, pooled, V2, calibration, counts).
- **A10**: `divergence_share` (|v_chosen − v_log| > 2 m/s).
- **A13**: `fallback_strata` from the fits' `Mstar_ip_src` (share of (fold, step ≤ 2 s) thresholds from a coarser level), as `fallback_share` / `fallback_any` columns in every per-stratum table (`cells`, `cal_cells`, `cal_l0_PD7`, `records_by_cell_Mstar`).
- **Paired contrasts** at identical decision states for every arm pair (`k8_<tag>_decide_paired.csv`: 14 endpoints incl. V1/V2 scene rates; JSON keeps the contrasts against M*). In the decision mode every arm decides at the same keyframes, so per-scene mean differences are means of per-decision differences.
- **D14 section 6 forms** A, B, C reported (`d14_forms`), with the trade-off table (`k8_<tag>_decide_tradeoff.csv`).
- **Loop mode**: K7's populations, progress contrasts and outcome summary, plus the per-decision endpoints per arm (and per delay), V2 on PL7 / PL / SL1_7, paired contrasts against M*.
- **Consistency check**: for every arm the per-decision relied-on counts equal the PD7 records and exceedances of the counts table (`consistency_decisions_vs_counts`).
- Outputs: JSON `--out`; CSVs `k8_<tag>_decide_{arms, cells, v2, sweep, paired, validity, cal_cells, cal_l0_PD7, counts, calibration, tradeoff}.csv` and `k8_<tag>_loop_{arms, paired_vs_Mstar}.csv`.

## Not implemented as specified, or read differently

- A3 "smallest δ'": read as the least conservative qualifying δ' (above).
- A5 "minimum longitudinal gap": the pair gap along the relied-on separating axis of the object frame (what the planner enforces), not a gap along the ego's heading.
- A6 energy score: Monte Carlo with 200 fixed draws, not a closed form.
- A6 on the loop runs: the calibration table is accumulated but mixes sensor offsets; the loop analysis reports V1/V2 and the operability and safety endpoints, not the calibration set (A6 is defined on the decision-mode PD7 items).
- The confirmatory binding (`check_binding`) is kept in K7's form and cannot run until a K8 plan and freeze record exist.
