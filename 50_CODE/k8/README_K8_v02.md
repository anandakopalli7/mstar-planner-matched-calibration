## How to launch the exploratory run (both trackers)

Run from `50_CODE/k8`. Do **not** edit any file in `CODE_FILES` (sim, runner, analysis, `k6_sim_v02`, `k6_analyse_v02`, `m_lib_v04`), the fits or the manifests between launch and analysis: the runner re-checks at the end and the analysis refuses mismatches. First the dry runs (they read only the manifests):

```
PY=../env/canmot310/Scripts/python.exe
OUT=../../70_TESTS/k8_expl_v02          # any new directory
FIT=../../60_RESULTS/k7_fits_v01
for t in t1 t3; do C="../../30_DATA/k6/cache_v02_${t}_train ../../30_DATA/k6/cache_v02_${t}_val"
  for m in decide loop; do $PY -B k8_run_v02.py --caches $C --fits $FIT/k7_fits_${t}_v01.json --tag ${t}_${m} --mode $m --out $OUT --exploratory --dry-run; done
  $PY -B k8_items_v02.py --caches $C --out $OUT/items_k8_v02_expl_${t}.npz --exploratory --dry-run; done
```

Then the run itself (decision mode first, loop second; `--resume` restarts an interrupted run from its shards):

```
for t in t1 t3; do C="../../30_DATA/k6/cache_v02_${t}_train ../../30_DATA/k6/cache_v02_${t}_val"
  $PY -B k8_items_v02.py --caches $C --out $OUT/items_k8_v02_expl_${t}.npz --exploratory --workers 6
  $PY -B k8_run_v02.py --caches $C --fits $FIT/k7_fits_${t}_v01.json --tag ${t}_decide --mode decide --out $OUT --exploratory --workers 6 --resume
done
for t in t1 t3; do C="../../30_DATA/k6/cache_v02_${t}_train ../../30_DATA/k6/cache_v02_${t}_val"
  $PY -B k8_run_v02.py --caches $C --fits $FIT/k7_fits_${t}_v01.json --tag ${t}_loop --mode loop --out $OUT --exploratory --workers 6 --resume
done
$PY -B k8_analyse_v02.py --runs $OUT --tags t1 t3 \
    --manifests ../../30_DATA/k6/cache_v02_t1_train/MANIFEST.json ../../30_DATA/k6/cache_v02_t1_val/MANIFEST.json \
    --out $OUT/k8_exploratory_analysis_v02.json --csv-dir $OUT/csv --exploratory \
    --fits $FIT/k7_fits_t1_v01.json $FIT/k7_fits_t3_v01.json \
    --items $OUT/items_k8_v02_expl_t1.npz $OUT/items_k8_v02_expl_t3.npz
```

## Not implemented, or read differently

- **TTV, "over the enforced tracks"**: read as every check time (to 4 s) of every track with an enforced pair; `ttv_enf` gives the reading that skips exempt pairs within 2 s. On dev the TTV < 2 s share is identical across arms (exempt conflicts only: no arm can violate an enforced pair within its 2 s horizon), so arms differ only through TTV in 2-4 s; the paper should read `ttv_share_lt_4s` / `ttv_enf_share_lt_4s` alongside.
- **Form B comparators**: B0, B1, B3, B4, B6, B9 and RETUNED. Single alpha / delta' grid points are not comparators (choosing the best of 21 in-sample points would bias against M*); they are reported in the trade-off table.
- **Executed-margin V2**: the emergency stop is scored at lam = 0 (no margin is executed).
- **A6 gross errors**: defined arm-independently by B0's NEES (> 27.63); per-arm counts above the same threshold are also reported.
- **A6 primary for the loop runs**: not computed (A6 is defined on the decision-mode PD7 items).
- **RETUNED's relied-pair (secondary) A6**: dropped, because the in-loop calibration table of a delta' arm uses B0's covariance and RETUNED copies those rows where a fold selects a delta' point; RETUNED's A6 is in the items table under alpha_sel(fold).
- The exploratory analysis could not be exercised end to end (no 840-scene runs exist, by rule); its binding check is tested on synthetic records carrying scene names only (T12), and every statistic it computes is the dev path with the confirmatory evaluability and strict quantiles.
